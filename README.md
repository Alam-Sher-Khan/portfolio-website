# 🚀 Portfolio Website Deployment with GitHub Actions & AWS S3

This project demonstrates how to **deploy a static website** using  
**GitHub Actions (CI/CD)** and **AWS S3 (Static Website Hosting)**.  

It’s a beginner-friendly but real-world DevOps + Cloud project.

---

## 📌 Architecture

<img width="1536" height="1024" alt="Entwicklungsprozess für Portfolio-Website" src="https://github.com/user-attachments/assets/d9844f48-132a-43b5-990f-74cc870d550b" />


**Flow:**
1. Developer pushes code to GitHub repository.  
2. GitHub Actions workflow is triggered.  
3. The workflow syncs website files to **AWS S3**.  
4. S3 serves the static site to end users.  

---

## ⚙️ Tech Stack
- **Frontend**: HTML, CSS (static website)  
- **Version Control**: Git & GitHub  
- **CI/CD**: GitHub Actions  
- **Cloud Provider**: AWS  
- **Hosting**: Amazon S3 (Static Website Hosting)
